# Art-direction research (2026-10-15)

Read-only research pass; prioritized recommendations. Status is updated as they land.

Diagnosis: every building had the same proportions (height/side ≈ 2.5), squarify put each district's big files in the same corner, and centred footprints left 1–2 block grass rings around everything.
