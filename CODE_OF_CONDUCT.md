# Code of Conduct

Be kind, assume good intent, and keep criticism about code and ideas, not people. Harassment, discrimination and personal attacks are not tolerated in issues, PRs or discussions. Maintainers may remove content and block participants who break these rules. Report problems to the maintainer via GitHub.

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
