# Security

Repoville reads files and git history from repositories you point it at. It never executes code from those repositories, ignores `repoville.config.json` inside cloned remote repos, writes outputs only to the folder given with `-o`, and runs `git` without a shell.

Please report vulnerabilities privately via GitHub's "Report a vulnerability" (Security tab) rather than a public issue. You can expect a reply within a few days.
