The legend

Every block means something.

The city is generated from your files and your git history. Same commit in, same city out: layout and decoration are deterministic.

Folders → districts
Nested folders become nested districts with roads, a plaza and a name sign. Big folders sit downtown.
Files → buildings
Height is 4 + 4·√(lines/10). Small files are houses, big ones are towers; tests are lighthouses, docs are libraries.
Churn → fire
The 10% most-changed files of the last year burn on the roof; the top 2% get soul fire.
TODOs → ruins
The share of TODO/FIXME/HACK lines becomes the share of cracked and cobwebbed wall.
Untouched → moss
Files without a commit for over a year grow moss and vines.
Language → theme
TS/JS plains, Rust nether, Python jungle, Go frozen peaks, Java badlands, C/C++ deep caves, Ruby cherry grove.

Look closer

Pixel-perfect up close.

Every block carries a 16×16 pixel texture drawn by Repoville itself. Prefer the original look? Switch on Minecraft textures in the viewer and your browser loads them at runtime; they are never bundled.

Metrics, not judgement

A metaphor you can switch off.

  • Fire is activity, not bad code. Busy files are often the most important ones.
  • Moss is age, not rot. Stable code that nobody needs to touch is a good sign.
  • Exact numbers are one click away. Every building shows lines, commits, last touch and TODO count, and the metric view swaps the city for plain columns.

One command

Point it at a repo.

A local folder, owner/repo or any git URL. Remote repos are cloned without file contents first, then analysed on your machine. An npm release is coming; until then run it from source.

# from source (Node 22+)
$ git clone https://github.com/maximilianfeix/repoville
$ cd repoville && npm ci && npm run build
$ node dist/cli.js facebook/react --format html,schem
  7165 files · 903,811 LOC · 3294 buildings
  wrote html      repoville-out/facebook-react.html
  wrote schem     repoville-out/facebook-react.schem

Your code stays on your machine.

Local analysis

Counting lines and reading git history happens locally. Nothing is uploaded, and there is no telemetry.

Paths and counts only

The city file contains file paths, line counts and commit counts, never file contents.

Nothing runs

Repoville never executes code from the repos it renders, and ignores config files from cloned repos.
